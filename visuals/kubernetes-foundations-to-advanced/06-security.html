🚦 The API Request Pipeline

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Step by step

  1. Request → 🪪 Authentication who are you? certs, OIDC, SA tokens
  2. 🪪 Authentication who are you? certs, OIDC, SA tokens → 📜 Authorization are you allowed? RBAC
  3. 📜 Authorization are you allowed? RBAC → ✏️ Mutating admission inject defaults, sidecars
  4. ✏️ Mutating admission inject defaults, sidecars → ✅ Validating admission policy checks PSA, Kyverno, Gatekeeper, ValidatingAdmissionPolicy
  5. ✅ Validating admission policy checks PSA, Kyverno, Gatekeeper, ValidatingAdmissionPolicy → etcd

👥 RBAC

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Step by step

  1. 👤 User / Group → RoleBinding namespaced
  2. 🤖 ServiceAccount → RoleBinding namespaced
  3. 👤 User / Group → ClusterRoleBinding cluster-wide
  4. RoleBinding namespaced → Role verbs on resources in one namespace
  5. RoleBinding namespaced → ClusterRole cluster-wide or reusable
  6. ClusterRoleBinding cluster-wide → ClusterRole cluster-wide or reusable

🤖 ServiceAccounts (Workload Identity)

Pod ──uses──▶ ServiceAccount "api" ──RBAC──▶ K8s API permissions                     │                     └──(IRSA / Workload Identity)──▶ ☁️ cloud IAM role                                                     (S3, GCS, KeyVault)

👀 The drawing is revealed line by line. Arrows pulse, and ✅ / ❌ marks pop in to show the verdicts.

  • Each namespace has a default SA. Create dedicated SAs per app.
  • Set automountServiceAccountToken: false when the app doesn't call the API.
  • Tokens are short-lived and projected (bound tokens).

📦 Supply Chain Security

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Step by step

  1. 💻 Code → 🏗️ Build minimal / distroless base
  2. 🏗️ Build minimal / distroless base → 🔍 Scan Trivy, Grype
  3. 🔍 Scan Trivy, Grype → ✍️ Sign + SBOM cosign, Syft
  4. ✍️ Sign + SBOM cosign, Syft → 📦 Registry
  5. 📦 Registry → 🛂 Admission verify signature, allowed registries
  6. 🛂 Admission verify signature, allowed registries → ☸️ Cluster ✅
  7. 🛂 Admission verify signature, allowed registries → Rejected ❌
