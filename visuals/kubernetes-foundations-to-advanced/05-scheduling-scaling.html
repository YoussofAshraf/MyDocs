🩺 Health Probes

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Probe Question On failure
startupProbe Has the app finished starting? Restart (holds off the other probes until it passes)
readinessProbe Can it serve traffic now? Removed from load balancing, not restarted
livenessProbe Is it deadlocked or broken? Container restarted

Step by step

  1. Container starts → startupProbe finished booting?
  2. startupProbe finished booting? → 🔁 restart fail too long
  3. readinessProbe ready for traffic? → 🚫 removed from Service endpoints fail
  4. livenessProbe still alive? → 🔁 restart container fail
  5. … → … pass

🎯 Controlling Placement

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Tool Says Example
nodeSelector "Only nodes with this label" disktype: ssd
Node affinity Required or preferred node rules "prefer zone eu-west-1a"
Pod affinity "Near Pods like X" Cache next to the app
Pod anti-affinity "Away from Pods like X" Replicas on different nodes
Taints & tolerations Node: "keep out unless you tolerate me" GPU nodes, dedicated nodes
Topology spread "Spread evenly across zones or nodes" HA across AZs

Step by step

  1. Pending Pod → 1 · Filter resources, taints, node affinity, volumes
  2. 1 · Filter resources, taints, node affinity, volumes → 2 · Score spread, affinity weight, least allocated
  3. 2 · Score spread, affinity weight, least allocated → 3 · Bind best node wins 🏆

Step by step

  1. metrics-server → HPA: avg CPU = 85% (target 60%)
  2. HPA → Deployment: replicas 3 → 5
  3. Deployment ⇠ Cluster Autoscaler: 2 Pods Pending (no room)
  4. Cluster Autoscaler → Cluster Autoscaler: provision new node ☁️
  5. 📝 Deployment: Pods scheduled ✅
