💾 Storage

The PV / PVC / StorageClass model

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Step by step

  1. Pod → PersistentVolumeClaim 'I need 20Gi RWO' 👩‍💻 dev mounts
  2. PersistentVolumeClaim 'I need 20Gi RWO' 👩‍💻 dev → PersistentVolume actual disk ⚙️ cluster bound to
  3. StorageClass 'fast-ssd' 🛠️ admin → PersistentVolume actual disk ⚙️ cluster dynamically provisions
  4. PersistentVolume actual disk ⚙️ cluster → ☁️ EBS / PD / Azure Disk / Ceph
  5. CSI Driver ⇢ ☁️ EBS / PD / Azure Disk / Ceph
