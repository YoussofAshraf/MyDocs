🩻 Troubleshooting Flow

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Step by step

  1. Pod not working → k get pod: STATUS?
  2. k get pod: STATUS? → k describe pod → Events • Insufficient cpu/memory • taint not tolerated • PVC unbound Pending
  3. k get pod: STATUS? → Wrong image or tag, private registry → imagePullSecrets ImagePullBackOff
  4. k get pod: STATUS? → k logs --previous bad config, missing env, failing liveness probe CrashLoopBackOff
  5. k get pod: STATUS? → Raise memory limit or fix the leak OOMKilled
  6. k get pod: STATUS? → readiness failing? k get endpointslices Service selector ≠ Pod labels? NetworkPolicy? Running but no traffic
