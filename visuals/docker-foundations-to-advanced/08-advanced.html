⚡ BuildKit Superpowers

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

BuildKit is the default builder. It builds stages in parallel, skips unused stages and supports special mounts.

Step by step

  1. FROM base → stage: deps
  2. FROM base → stage: lint
  3. FROM base → stage: test
  4. stage: deps → stage: build
  5. stage: build → stage: final
  6. stage: lint ⇢ stage: final skipped if not needed by --target

🔁 CI/CD Pipeline

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Step by step

  1. git push → lint Dockerfile hadolint
  2. lint Dockerfile hadolint → buildx build cache from registry
  3. buildx build cache from registry → test inside the image --target test
  4. test inside the image --target test → scan Scout / Trivy
  5. scan Scout / Trivy → push multi-arch + SBOM + provenance
  6. push multi-arch + SBOM + provenance → cosign sign
  7. cosign sign → deploy by digest Compose / K8s / ECS
