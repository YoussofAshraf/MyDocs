🧰 Instruction Reference

ENTRYPOINT vs CMD

  ENTRYPOINT ["python", "app.py"]  CMD        ["--port", "8000"]   docker run img                 →  python app.py --port 8000  docker run img --port 9000     →  python app.py --port 9000     (CMD replaced)  docker run --entrypoint sh img →  sh                            (ENTRYPOINT replaced)

👀 The drawing is revealed line by line. Arrows pulse, and ✅ / ❌ marks pop in to show the verdicts.

💡 Always use the exec form ["cmd", "arg"]. The shell form cmd arg wraps your process in /bin/sh -c, so it doesn't receive SIGTERM and won't stop gracefully.

🧅 Layers & the Build Cache

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Rule: once a layer misses the cache, every layer after it is rebuilt. So order instructions from least to most frequently changed.

Step by step

  1. FROM node:22-slim ✅ cached → COPY package*.json ✅ cached
  2. COPY package*.json ✅ cached → RUN npm ci ✅ cached
  3. RUN npm ci ✅ cached → COPY . . ❌ source changed → rebuild
  4. COPY . . ❌ source changed → rebuild → CMD ... ❌ rebuilt (everything after a miss)
