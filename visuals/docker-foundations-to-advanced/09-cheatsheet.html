🩻 Troubleshooting Flow

👀 Boxes light up as the flow reaches them and each arrow draws in the order the guide defines it. Glowing dots keep running along the arrows to show which way things move.

Step by step

  1. Container problem → docker ps -a: STATUS?
  2. docker ps -a: STATUS? → OOM → raise --memory or fix the leak docker inspect .State.OOMKilled Exited 137
  3. docker ps -a: STATUS? → docker logs c missing env, bad config, dependency not ready Exited 1 / restarting
  4. docker ps -a: STATUS? → Command not found wrong CMD / missing binary in a slim image Exited 127
  5. docker ps -a: STATUS? → Port published? docker port c App listens on 0.0.0.0, not 127.0.0.1? Same network? Firewall? Up but unreachable
  6. docker ps -a: STATUS? → uid mismatch on mount -u, chown, :z on SELinux Permission denied
  7. docker ps -a: STATUS? → Order layers, .dockerignore, cache mounts Build slow
